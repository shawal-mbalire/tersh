1. FOUNDATIONS AND INSPIRATIONS
-------------------------------

1.1 Alacritty
    https://github.com/alacritty/alacritty
    Copyright 2020 The Alacritty Project (Joe Wilm, Christian Duerr and contributors)
    License: Apache-2.0 (alacritty_terminal); vte: Apache-2.0 OR MIT

    tersh's terminal emulation is alacritty_terminal: escape-sequence parsing
    (through vte), the grid, scrollback, selection and terminal modes all
    come from it. tersh's key encoding follows Alacritty's behaviour, and
    Alacritty's focus on a fast, minimal terminal inspired tersh's.
    Used in: backend/adapters (AlacrittyEmulators).

1.2 Tauri
    https://github.com/tauri-apps/tauri
    Copyright (c) 2017 - Present Tauri Apps Contributors;
    plugins: Copyright 2019-2022, The Tauri Programme in the Commons Conservancy
    License: Apache-2.0 OR MIT

    The desktop app is a Tauri application: the window, the system webview,
    the IPC channels between the Rust backend and the page, the card
    protocol, the clipboard plugin and the bundler that produces the
    installers.
    Used in: backend/desktop (tauri, tauri-build, tauri-plugin-clipboard-manager),
    frontend/src/adapters/tauri (@tauri-apps/api, @tauri-apps/plugin-clipboard-manager).

1.3 Angular
    https://github.com/angular/angular
    Copyright (c) 2010-2026 Google LLC. https://angular.dev/license
    License: MIT

    The page's shell is an Angular application: the root component, the
    dependency injection that plugs adapters into the page, and the
    ahead-of-time compiler. Angular depends on RxJS (Apache-2.0) and tslib
    (0BSD, Copyright (c) Microsoft Corporation).
    Used in: frontend/src/adapters/angular, frontend/src/providers.ts.

1.4 kitty
    https://github.com/kovidgoyal/kitty
    Copyright (C) Kovid Goyal
    License: GPL-3.0 (kitty itself)

    An inspiration only: tersh contains no kitty code. tersh implements the
    kitty keyboard protocol, which kitty designed and documented
    (https://sw.kovidgoyal.net/kitty/keyboard-protocol/), so programs that
    ask for it can tell keys like Shift+Enter and Ctrl+I apart. Like kitty,
    tersh draws Nerd Font icons from a bundled symbols font whatever the main
    font is, and its rich cards owe a debt to kitty's idea that a terminal
    can show more than text.
